# Kalkulator Ratecard Influencer 💰

Website untuk menghitung estimasi ratecard influencer Instagram & TikTok.

## Fitur
- 📸 Kalkulator Instagram (Feed, Reels, Story, Carousel)
- 🎵 Kalkulator TikTok (Video, Review, Spark Ads, Live)
- 🏷️ Tier otomatis: Nano / Micro / Mid / Macro / Mega
- 📊 Faktor Engagement Rate, Niche, dan Lokasi
- 💡 Tips negosiasi per platform
